# Resume and interview wording

Use these bullets after running the project, completing the exercises and being able to explain the code and decisions. List under **Projects**, not employment. Do not describe generated work as professional experience.

**Workplace Systems Lab | Python, CSV, Access Reviews, Asset Management | Independent Project**

- Built and tested an offline systems review tool covering 6 fictional users and 6 Windows, macOS and Linux assets; generated 13 prioritized findings across access, endpoint posture, licenses and ticket queues.
- Flagged departed-user access, missing MFA, unverified endpoint protections and three potentially reclaimable SaaS seats totaling $39/month in a simulated dataset; exported HTML, CSV and JSON evidence with SHA-256 integrity hashes.

After completing the before/after exercise, optionally add: “Validated simulated remediation by rerunning the review and reducing findings from 13 to 0.” Do not use this bullet before you do the exercise.

## Honest skills positioning

Demonstrated by this repository: Python automation, CSV inventory review, access-review concepts, ticket documentation, remediation prioritization and evidence organization.

Documented concepts, not proven administration: Google Workspace, SSO, MFA recovery, MDM, VPN configuration and audit support. Add actual hands-on product skills only after using an authorized environment. This repository does not prove advanced Excel skills, antivirus deployment or real incident recovery.

Suggested explanation: “I am applying for my first IT support role. I used AI assistance to develop this independent lab, then ran it, traced the findings and practiced the workflows. It uses fictional exports rather than a live company tenant. I can demonstrate the checks and explain what would need approval in production.” Use only once true.

The supplied role asks for 1–3 years plus hands-on administration. This lab supports an application but does not replace that experience. Also search for Help Desk Technician I, Service Desk Analyst I, IT Support Trainee and Desktop Support Intern openings; assess each posting's actual requirements.
